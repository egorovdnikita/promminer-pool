# Promminer Pool — интерактивный прототип

Правдоподобный прототип личного кабинета майнинг-пула **Promminer** для тестирования фич
и прогона сценариев, которые невозможно воспроизвести на проде (там пустой аккаунт без данных).

**Прод:** https://pool.promminer.ru/

## Что это

Один самодостаточный файл [`index.html`](index.html) — HTML + CSS + ванильный JS, без сборки
и без зависимостей (кроме шрифта Manrope с Google Fonts как fallback для Gilroy).
Всё состояние приложения живёт в URL-хэше, поэтому любой сценарий можно скинуть ссылкой команде.

## Как открыть

```bash
open index.html
```

Либо через локальный сервер:

```bash
python3 -m http.server 4173
```

## Сценарии

Кнопка **⚙ Сценарии** в правом нижнем углу (или клавиша `S`) открывает панель переключателей.
Оси сценариев:

| Ось | Значения |
|---|---|
| Монета | BTC / LTC + DOGE |
| Наполнение данными | Норма / Пусто / Мало записей / Большие значения |
| Здоровье парка | Всё живо / Деградация / Авария |
| Роль | Владелец / Наблюдатель |
| Уровень рефералки | 5% / 10% / 15% / 20% / 25% |
| Верификация | Не пройдена / На проверке / Пройдена |
| Уведомления | 12 новых / 2 новых / Нет |
| Аккаунт | Основной / Суб-аккаунт |

Оси задаются в объекте `AXES` в начале скрипта — новый сценарий добавляется одной строкой.

## Разделы

- Главная
- Воркеры (список + карточка воркера)
- Финансы: Мои активы, Доход, Выплаты
- Отчёт о майнинге
- Инструменты: Калькулятор доходности, Калькулятор налогов
- Мониторинг (сводка по аккаунтам)
- Мои рефералы: Общая информация, Список рефералов, Реферальный доход, Реферальные выплаты
- Профиль, Безопасность, Уведомления, Суб-аккаунты, Наблюдатели, Верификация
- Вход / регистрация
