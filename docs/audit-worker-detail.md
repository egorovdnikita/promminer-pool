## Оговорка про цвет

Страница нарисована в режиме **Gray** (`#111827` / `#6b7280` / `#9ca3af`),
а прототип реализует **Neutral** — это известное расхождение из
[audit-tokens.md](audit-tokens.md), общее для всех макетов, и в правки
по этому экрану оно не входит. Ниже сравниваются **роли** токенов:
Primary / Secondary / Tertiary, а не конкретные шестнадцатеричные коды.

## 7. Данные, а не вёрстка

- **Имя в заголовке.** В макете это идентификатор вида `ba3617558a88`,
  в прототипе — имя из списка (`Ant01`). Сделано намеренно: иначе переход
  из таблицы вёл бы на экран с другим именем. Решение за дизайнером —
  если в шапке должен быть идентификатор, его надо показывать и в таблице.
- **Подписи делений графика** масштабируются вместе с svg: точны на 1920
  и мельче на 1440. Общее свойство движка графиков, лечится выносом
  делений из svg в HTML сразу для всех экранов.
