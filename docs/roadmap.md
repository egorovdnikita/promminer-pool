# Roadmap

## Сделано

- Каркас: сайдбар с группами и сворачиванием, хедер, футер
- Панель сценариев (8 осей), состояние в URL, шеринг ссылкой
- Экраны: Главная, Воркеры, Карточка воркера, Мои активы, Доход, Выплаты,
  Отчёт о майнинге, Калькулятор доходности, Калькулятор налогов, Мониторинг,
  Реферальная программа (4 подраздела), Профиль, Безопасность, Уведомления,
  Суб-аккаунты, Наблюдатели, Верификация, Вход
- Дропдауны хедера: уведомления, аккаунты, профиль
- Модальные окна, тосты, пустые состояния
- Иконки Solar Bold Duotone из дизайн-системы
- Интерактив: сортировка таблиц, пагинация, поиск, чекбоксы и массовые действия,
  сегмент-контролы, фильтр воркеров по плиткам
- Разбор прода (см. `docs/prod-analysis.md`) и перенос фактических значений:
  настоящий Gilroy, токены дизайн-системы, логотип и favicon, тёмная тема,
  экраны входа `/login` `/register` `/restore` + шаг с кодом, внешние адреса
- Раздел «Личный кабинет» переведён на общие данные (`SUBS`, `OBSERVERS`, `SESSIONS`):
  счётчики вкладок, сводка и вкладки больше не расходятся, сценарий «Пусто» действует
  на весь раздел; активные сессии, каналы уведомлений с привязкой Telegram-бота,
  набор полей верификации зависит от типа лица
- Сверка внутренних экранов по скриншотам авторизованного аккаунта: иконки сайдбара,
  попоувер «Сводка по аккаунтам» на балансе, меню профиля с аватаром и иконками,
  широкий попоувер уведомлений, пересобранный «Личный кабинет», «Мои активы»
  с логотипами монет и плитками-действиями, футер и подписи осей графика
