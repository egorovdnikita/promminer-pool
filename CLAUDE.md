# Promminer Pool — прототип

Прототип личного кабинета майнинг-пула. Один файл `index.html` (HTML+CSS+vanilla JS, без сборки).
Контекст, ссылки на макеты и дизайн-токены — в `docs/context.md`, план — в `docs/roadmap.md`.

## Правила работы

- Не вводить сборку, фреймворки и npm-зависимости — прототип должен оставаться одним файлом,
  который открывается двойным кликом и дёшево обновляется точечными правками.
- Внешний вид сверять с макетами Figma и дизайн-системой (список файлов — в `docs/context.md`);
  макеты бывают на разных страницах одного файла.
- Иконки — инлайн-SVG в стиле Solar Bold Duotone (объект `I` в скрипте), заливка `currentColor`,
  вторичные формы `opacity .5`.
- Новый сценарий добавляется осью в объект `AXES`; состояние сериализуется в URL-хэш.
- Взаимоисключающий выбор (вкладки, периоды, тип лица, монета) — только компоненты
  дизайн-системы: `seg()` (Segment Control) или `segLine()` (Segment Control Line,
  модификаторы `fill`, `inv` для цветной подложки). Чипы — только для фильтров
  и множественного выбора.
- Хедер `.top` зафиксирован при скролле (`position:sticky`), а панель хедера, карточки
  и футер делят одни левую и правую границы: горизонтальные отступы живут на `.main`,
  у `.page` их нет.
- Прод для сверки данных и формулировок: https://pool.promminer.ru/

## Структура index.html

1. Токены и стили (`:root`, компоненты)
2. `AXES` / `DEF` / `S` — сценарии и состояние
3. `COINS`, `HEALTH`, `TIERS` — данные; `M()` — модель текущего сценария
4. `I` — иконки
5. `NAV`, `TITLES`, `GROUP_OF` — навигация
6. Общие блоки: `card`, `emptyBox`, `seg`, `pager`, `cb`, `chart`
7. `V.*` — экраны
8. Хедер, сайдбар, попоуверы, модалки, роутер, обработчики
